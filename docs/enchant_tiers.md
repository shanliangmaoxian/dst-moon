# 人物附魔强度分级（讨论稿）

> 基于 `scripts/enchants/` 全部 48 个附魔 + `modmain.lua` 启用状态的代码审阅。
> 目的：建立一套可复用的分级框架，找出超模项（建议削弱）与偏弱项（建议加强）。

## 一、分级框架（为什么这么分）

单纯看"伤害数字"分不出强弱，因为有的附魔是**乘区**（攻速、攻击倍率、真伤），有的是**数值**（固定 200 点伤害），后期价值完全不同。按 4 个维度打分（每项 0~10）：

| 维度 | 考察点 |
|------|--------|
| 输出收益 | 是否乘区（攻速/倍率/暴击）、真伤、按 % 生命结算、叠层上限 |
| 生存收益 | 免伤/限伤、免疫控制、回复、免死、免仇恨 |
| 功能收益 | 经济（掉落/采集/双倍）、移速、联机协作、QoL |
| 使用成本 | 触发条件、负面代价、内置 CD、限定角色/装备/mod 联动 |

**定档规则：**

- **T0 超模**：战斗维度单项 ≥9 且无条件常驻 → 建议削弱，或作为"毕业附魔"锚点
- **T1 强力**：综合 25~31，或单项 ≥8 但有明显条件/代价
- **T2 均衡**：综合 18~24，与原版机制互补，可作基准线
- **T3 一般**：综合 10~17，固定数值或场景窄，后期乏力
- **T4 娱乐/工具**：战斗价值 ≈0，纯特效、互动或工具类
- **特化型**（标注 ⚙）：自带大额负面或限定装备，自成玩法（换装流/挂机流），不按常规分档

**辅助标签**：`常驻` 无条件生效 / `条件` 需触发 / `限定` 角色或装备限定 / `叠加` 可多件叠加 / `联动` 依赖其他 mod。

## 三、超模项的具体削弱建议（T0）

1. **小蝴蝶**：限伤 10% → 改为 20~30%，或加"限伤触发后 3s CD"；免疫制裁/反伤可保留
2. **萝的守护**：基础 50% 免伤 → 30%，叠层上限 +30% → +20%（合计 50%）；`notarget` 影怪无视建议删掉（影响机制而非数值）
3. **寒月公主**：666 真伤改为随天数/对手血量缩放；暴击 +66%/爆伤 +666% 拆一半进试炼奖励

## 四、偏弱项的加强方向（T3）

- **胖虎**：固定 200 → 按武器攻击力百分比（如 200% 攻击力）
- **毛旭**：+200 → +500 且保留可叠加，或改为 +10% 最大生命
- **怀民**：随机 buff → 让玩家可以指定，或白天也生效

## 五、后续维护建议

- 新附魔落表：加一个 `tier` 字段到注册处（`AddSpecialEquipEffect` 表内加 `tier = "T1"`），UI 按档位着色，掉落权重也按档位挂钩（T0 权重远低于 T2）
- 掉落权重现状：多数 0.01，萝的守护/新史低 0.005，怀民/良弓藏 0.008 —— 目前权重和强度基本无关，可顺势对齐

> **已落地（2026-09-04）**：权重对齐通过中央表实现——`scripts/enchants/tier_config.lua`
> 维护 `TUNING.MOON_ENCHANT_TIERS`（ID → 档位）与 `TUNING.MOON_ENCHANT_TIER_WEIGHTS`
> （档位 → 权重：T0=0.002 / T1=0.005 / T2=0.01 / T3=0.012 / T4=0.004），
> `drop_utils.lua` 注册时查表覆盖。新附魔上线后只需在中央表补一行。

## 六、调整方案（怎么调更合理）

### 6.1 先定基准，再谈强弱

"合理"取决于服务器定位，先回答一个问题：**这套附魔服务的是休闲社交服还是硬核 PVE 服？**

- 休闲服：经济附魔（打工人/劳动/橙汁）不用动，只削战斗端 T0
- 硬核服：经济大杀器也要降档（秒锅+秒采直接改变游戏节奏）

基准线定在 **T2**（原版机制的合理延伸），目标是让 T0→T1→T2 形成平滑曲线，而不是现在"断崖"。

### 6.2 统一衡量口径（乘区意识）

所有效果换算成两个数再比较：

- **有效 DPS 增幅** = 对基准怪（如蜘蛛战士）的击杀时间缩短比例
- **有效生命 EHP 增幅** = 被基准 Boss 击杀所需攻击次数的放大比例

判断规则：
- 固定数值伤害（胖虎 200、寒月 666）→ 后期趋近 0%，天然该弱，问题只在"前期是否过强"
- 百分比乘区（攻速、倍率、吸血）→ 不会过时，超模的都是这类
- 限伤/免伤 → 直接换算 EHP：限伤 10% ≈ EHP×10，这就是小蝴蝶的强度真相

### 6.3 三类超模问题，用不同的刀

| 类型 | 案例 | 正确处理 |
|------|------|----------|
| 数值封顶型 | 小蝴蝶限伤 10%、雨纷纷限伤 1% | 调整封顶值即可，机制本身没问题 |
| 机制免疫型 | 萝的守护免僵直/击退/影怪仇恨 | 免疫组不能堆叠在一个附魔上，要拆出去 |
| 无衰减乘区型 | 寒月 666 真伤、月半按当前生命 5%、fay 8% 已损失 | 给上限（min）或改为按自身攻击力结算 |

### 6.4 T0 三件的具体方案（两档力度任选）

**小蝴蝶**（特色 = 免疫组，削数值不削特色）
- 轻削：限伤 10% → 20%，保留全部免疫
- 重削：限伤 20% + 限伤触发后 3s 内不再限伤（防连击流溢出）

**萝的守护**（特色 = 叠层守护，问题 = 免疫组堆叠 + notarget 改机制）
- 轻削：50% → 35% 基础免伤，叠层上限 +30% → +20%（合计 55%）
- 重削：删 `notarget`（这是改机制不是改数值）；免僵直/击退拆出去做成独立低阶附魔
- 免伤改"触发型"备选：50% 概率免伤保留，但免伤失败不叠加守护层

**寒月公主**（特色 = 冰控 + 爆发，问题 = 666 真伤无衰减 + 暴击爆伤堆叠）
- 轻削：666 真伤 → `min(666, 目标最大生命×1%)`；暴击 +66%/爆伤 +666% 拆一半进试炼升级版
- 重削：永冻改为"冻结 2s + 缓速"，每秒 2% 最大生命保留（控制 paid by DoT）

### 6.5 T1 中偏强的收敛（次优先级）

- 一枝独秀：solo 翻倍 → solo 改为 +50%（而非 ×2），保留"独狼更强"的定位
- 月半：当前生命 5% → `min(5%当前生命, 500)`，掐掉血牛流的溢出
- 幸运橙汁/摸瓜吃鱼：休闲服不动；硬核服额外掉率 30%/50% → 20%/30%

### 6.6 弱项加强：换结算方式，而不是加数字

- 胖虎：固定 200 → 200% 自身攻击力（前期不变弱，后期跟得上）
- 毛旭：+200 → `min(+500, +10%最大生命)` 且保留可叠加
- 怀民：随机 buff → 睡前可选方向（伤害/移速/减伤三选一）
- 番茄炒蛋：加"每 5s +20san"之外补 1 条战斗成分（如满 san 时 +10% 伤），或干脆定位纯 QoL 并把掉率提到 0.02

### 6.7 落地节奏（建议顺序）

1. **第一步（零风险）**：注册表加 `tier` 字段 + UI 着色，掉落权重按档位对齐 → 玩家侧先建立"稀有 = 强"的预期
2. **第二步（小版本）**：削 T0 三件（轻削档），观察 1~2 周
3. **第三步**：按实测数据决定是否走重削档，同时收敛 T1 偏强项
4. **第四步**：加强 T3，补齐"前期开荒有用"的体验

### 6.8 验证方法（削完怎么知道合理）

打靶表：满配毕业装角色 vs 三个基准目标，记录击杀时间与受击次数——

| 基准目标 | 期望击杀时间（持 T1 毕业装） |
|----------|------------------------------|
| 蜘蛛战士 ×1 | ≤ 4 刀 |
| 克劳斯（无小怪阶段） | ≤ 60s |
| 蜂王 | 90~150s（Boss 应该明显更久） |

削前先跑一遍记录基线，削后对比，比"感觉弱了"可靠得多。
